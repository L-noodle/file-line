## 功能特性

- **拖入即挂**：把文件、文件夹直接拖到绳子上，变成一张张卡片晾起来
- **截图自动晾**：截图后自动挂到绳子上
- **卡片交互**：
  - 单击：复制（图片进剪贴板，文件进文件列表）
  - 双击：用默认程序打开
  - 按住拖出：拖到聊天窗口、桌面等任意地方
  - 右键菜单：打开 / 打开所在文件夹 / 取下 / 取下左侧全部 / 取下右侧全部 / 另存为 / 清空绳子
- **待办卡片**：新增的待办会挂到绳子上，悬停卡片可打勾完成 / 取消完成，完成后置灰并加删除线
- **倒计时卡片**：新增的倒计时会挂到绳子上，卡片底部实时倒数，渐近展示天 / 时 / 分 / 秒；截止后置灰并显示「已截止」
- **托盘**：双击托盘图标显示 / 隐藏绳子；右键托盘菜单可新增便笺 / 待办、打开笔记本、设置开机启动、切换卡片大小（小 / 中 / 大）、退出
- **自动隐藏**：闲置后滑出屏幕收起，鼠标放到屏幕顶部重新出现；拖拽着文件靠近顶部时立即弹出
- **状态持久化**：卡片清单自动保存，重启应用后原样恢复

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Win11 与较新的 Win10 已内置）
- [Node.js](https://nodejs.org/) 18+（推荐 20 LTS）
- [Rust](https://www.rust-lang.org/tools/install) stable（建议 1.78+，安装 MSVC toolchain 目标）
- 磁盘留出约 3 GB 给 Rust 编译缓存（`src-tauri/target`）

## 开发启动

```bash
# 1. 安装依赖
npm install

# 2. 以开发模式启动（首次会编译 Rust，约几分钟）
npm run tauri dev
```

- 修改 `src/` 下的前端代码：Vite 热更新，即时生效
- 修改 `src-tauri/` 下的 Rust 代码：自动重新编译并重启应用

> Rust 拉取依赖慢时，可先设置镜像：
> `set CARGO_HTTP_MULTIPLEXING=false`，或参考 [RsProxy](https://rsproxy.cn/) 配置。

## 打包发布

```bash
npm run tauri build
```

构建完成后产物在：

| 产物 | 路径 |
| --- | --- |
| NSIS 安装包 | `src-tauri\target\release\bundle\nsis\FileLine_1.0.1_x64-setup.exe` |
| 绿色单文件 exe | `src-tauri\target\release\FileLine.exe` |
| Mac 安装包 | `src-tauri\target\release\bundle\dmg\FileLine_1.0.1_aarch64.dmg` |

- **安装包**：双击安装，含开始菜单 / 卸载入口；版本号随 `tauri.conf.json` 与 `Cargo.toml` 中的 `version` 变化
- **绿色版**：单个 exe，拷走即用，无需安装
- **Mac 版**：DMG 拖入「应用程序」文件夹即可

> 执行 `npm run build:app` 时，脚本会自动把当前平台的产物收集到仓库根目录的 `release/` 下。

## 基本使用

### 唤出 / 收起

| 操作 | 说明 |
| --- | --- |
| 双击托盘图标 | 显示或收起晾衣绳 |
| 鼠标贴到屏幕顶部 | 稍作停留即唤出 |
| 截图或复制文件 | 绳子自动出现，文件挂上新卡片 |
| 空闲约 2 秒 | 自动滑回收起，内容不会丢失 |

### 挂上卡片

| 操作 | 说明 |
| --- | --- |
| 拖文件 / 文件夹到屏幕顶部 | 松手即挂上绳子 |
| 复制到剪贴板的图片和文件 | 自动晾成新卡片 |

### 托盘菜单（右键托盘图标）

| 操作 | 说明 |
| --- | --- |
| 新增便笺 | 新建便笺并挂到绳子上，直接开写 |
| 新增待办 | 新建待办并挂到绳子上，设置时间与提醒 |
| 打开笔记本 | 管理全部便笺 / 待办 / 倒计时（置顶 / 挂起 / 删除） |
| 开机启动 | 随系统自动运行 |
| 卡片大小 | 切换 小 / 中 / 大 三档显示 |

### 卡片操作

| 操作 | 说明 |
| --- | --- |
| 单击卡片 | 复制该文件到剪贴板 |
| 双击卡片 | 用默认程序打开 |
| 拖动卡片上的衣夹 | 沿绳子左右移动，调整卡片顺序 |
| 按住卡片向外拖 | 作为文件拖进聊天窗口、编辑器 |
| 点击最右入口卡片 | 左图新建便笺，中图新建待办，下行新建倒计时，右图打开笔记本 |
| 右键卡片 | 打开、定位、取下、全部另存为等 |
| 悬停卡片右上角 × | 取下这张卡片 |
| 悬停待办卡片 | 打勾按钮完成 / 取消完成；打勾后卡片置灰并加删除线 |
| 双击倒计时卡片 | 打开编辑弹窗（名称 / 内容 / 截止日期），Ctrl + Enter 保存 |
| 倒计时底部倒数条 | 每秒刷新，渐近展示「N天 HH:MM:SS / N时M分S秒 / M分S秒」；截止后置灰并显示「已截止」 |

### 回看历史

| 操作 | 说明 |
| --- | --- |
| 在绳子上滚动滚轮 | 左右滑动回看更早的卡片 |
| 点击两端的折叠堆叠 | 展开列表，直接跳到某张卡片 |

### 倒计时与笔记本

| 操作 | 说明 |
| --- | --- |
| 入口卡片 / 笔记本「新增倒计时」 | 新建倒计时并挂到绳子上，随即打开编辑窗 |
| 笔记本 → 限时 Tab | 查看全部倒计时，行内实时显示剩余时间 |
| 笔记本 → 全部 Tab | 便笺 / 未完成待办 / 倒计时按创建时间穿插展示 |
| 笔记本右侧编辑面板 | 选中倒计时后可直接修改名称 / 内容 / 截止日期，实时写回 |

## 常见问题

- **托盘 / 窗口图标没更新**：资源管理器对图标有缓存，重启资源管理器或稍等片刻
- **截图没有自动挂上来**：确认应用正在运行（托盘有图标）；部分第三方截图工具不走系统剪贴板监听，需手动粘贴或拖入
- **想要开机自启**：托盘图标右键 → 勾选「开机启动」
